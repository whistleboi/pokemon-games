# Bulbapedia page links for missing assets

Companion to `ASSETS_NEEDED.md`. Open each page, screenshot the map / interior / battle scene yourself, then save under the path and **exact filename** listed.

**Base URL:** `https://bulbapedia.bulbagarden.net/wiki/`

### What to capture on each page
| Asset type | Look for | Target size |
|---|---|---|
| Town map | Overworld / town map image | ~1000×850 |
| Pokémon Center / Mart / NPC room | Interior screenshots | 1248×832 |
| Gym battle BG | Gym arena / battle screenshot | 630×355 |
| Route / dungeon battle BG | Location maps or in-battle shots | 630×355 |

**Generic interiors:** [Pokémon Center](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Center) · [Poké Mart](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9_Mart) · [Badge](https://bulbapedia.bulbagarden.net/wiki/Badge)

**URL tip:** Spaces → `_`. Apostrophes → `%27`. If a link 404s, search the location name on Bulbapedia.

**Priority:** do **REQUIRED** rows first; *(optional)* can wait or reuse a similar interior.
